# 智鉴黄精 —— AI 黄精品质检测系统

基于视觉大模型的**九蒸九晒黄精成品外观品质辅助评价**系统。上传黄精图片后，系统自动完成输入有效性判断、三个独立品质指标分析（根茎完整度、色泽均匀度、霉变风险），并按预设业务规则给出「合格 / 建议人工复核 / 不合格 / 无法评价」的综合结论。

当前版本使用 **Doubao-Seed-2.0-lite** 作为视觉分析模型；程序端负责输入校验、模型调用、结构化结果校验、最终业务规则与界面展示，未来替换为真实数据集训练的 ResNet18 时无需重写前端和业务逻辑。

## 功能特性

- **三个独立品质指标**：根茎完整度、色泽均匀度、霉变风险逐项独立判断，禁止跨指标联动推理。
- **严格结构化输出**：模型只返回固定 Schema 的 JSON，程序端进行枚举校验与解析容错。
- **程序端最终判定**：综合结论由程序按判定优先级重新计算，不直接信任模型给出的 overall。
- **有效 / 无效样本区分**：无法评价（输入不可靠）与不合格（品质有问题）严格分离。
- **工具台式 Web 界面**：顶部标题栏与服务状态灯，左侧图片上传与操作按钮，右侧实时检测日志，底部检测报告与历史记录。
- **多种上传方式**：支持点击选择、拖拽上传，以及 `Ctrl+V` 剪贴板粘贴上传（组件缺失时自动降级）。
- **真实服务状态灯**：每 20 分钟真实向模型 API 发起一次轻量连通性探测，绿点表示服务正常，红点表示连接异常。
- **实时检测日志**：右侧面板实时显示「校验 → 模型分析 → 结果解析 → 综合判定」四步进度。
- **检测记录本地持久化**：最近 20 条记录保存在浏览器 `localStorage`，刷新页面不会丢失；每次检测只记一条（已修复重复记录问题）。
- **后台运行日志**：记录请求耗时与调用状态，不记录 API Key、用户图片与完整 Prompt。
- **在线 / 演示双模式**：`online` 真实调用视觉模型，`demo` 用于演示容灾。
- **一键安装**：支持 Linux（Bash）与 Windows（Bat）安装脚本，含交互式菜单（安装 / 卸载 / 更新 / 检查 / 版本）。

## 快速开始

### 1. 获取代码

```bash
git clone https://github.com/VellowK/HJDetect.git
cd HJDetect
```

### 2. 创建虚拟环境并安装依赖

```bash
# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 配置环境变量

```bash
# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env
```

编辑 `.env`，填入你的火山引擎 API Key：

```text
ARK_API_KEY=你的真实APIKey
```

### 4. 启动

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

打开浏览器访问 `http://localhost:8501`，上传黄精图片即可开始检测。

也可以使用一键脚本（推荐）：

```bash
# Linux
bash scripts/install.sh
bash scripts/run.sh

# Windows
install.bat
run.bat
```

## 配置说明

所有配置通过 `.env` 文件管理，参考 [.env.example](.env.example)：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `ARK_API_KEY` | 火山引擎方舟 API Key，必填 | 无 |
| `ARK_BASE_URL` | Ark API 地址 | `https://ark.cn-beijing.volces.com/api/v3` |
| `ARK_MODEL` | 视觉分析模型 | `doubao-seed-2.0-lite` |
| `APP_MODE` | 运行模式：`online` / `demo` | `online` |
| `HOST` | Web 监听地址 | `0.0.0.0` |
| `PORT` | Web 端口 | `8501` |
| `LOG_LEVEL` | 日志级别：`DEBUG` / `INFO` / `WARNING` / `ERROR` | `INFO` |

安全要求：

- API Key 不得硬编码、不得提交 Git、不得写入日志。
- `.gitignore` 已排除 `.env`，请确保只在本地填写真实密钥。

## 界面布局

页面采用工具台式布局：

- **顶部标题栏**：项目名称、简介，以及右上角的**服务状态灯**。绿点（带呼吸动画）表示后端 API 连通正常，红点表示连接异常；状态每 20 分钟真实探测一次。
- **左侧 · 图片上传区**：支持拖拽、点击选择、`Ctrl+V` 粘贴三种上传方式；下方为「开始检测 / 重新上传 / 清空」三个操作按钮。
- **右侧 · 实时检测日志**：检测过程中实时滚动显示每一步进度（校验、模型分析、结果解析、综合判定）与耗时。
- **底部 · 检测报告 + 历史记录**：展示三个指标、综合评价、检测依据；最下方是最近检测记录列表。

## 使用指南

1. **上传图片**：拖拽图片到左侧上传框，或点击选择，或复制图片后点「粘贴剪贴板图片」按钮（`Ctrl+V`）。支持 JPG / JPEG / PNG，建议不超过 10 MB、短边不低于 720 px。
2. **拍摄建议**：浅色、纯色、低纹理背景，与黄精主体颜色差异明显；单视角拍摄，让目标黄精清晰可见。
3. **开始检测**：点击「开始检测」，右侧日志面板会实时显示分析进度，系统自动完成有效性判断与三个指标分析。
4. **查看结果**：底部检测报告区展示——
   - 三个独立指标（根茎完整度、色泽均匀度、霉变风险）分别展示；
   - 综合评价为「合格」「建议人工复核」「不合格」或「无法评价」；
   - 附带简短检测依据与异常区域文字描述。
5. **重新上传 / 清空**：点「重新上传」或「清空」可清除当前图片与本次日志，重新开始。
6. **历史记录**：页面底部展示最近 20 条检测记录，保存在浏览器本地（`localStorage`），**刷新页面不会丢失**；点「清空检测记录」可手动清除。记录仅保存在你自己的浏览器，服务端默认不永久保存用户图片。

### 综合判定规则

程序端按以下优先级给出最终结论：

1. 样本无效 → **无法评价**（输入不满足可靠评价条件，不代表品质不合格）
2. 霉变风险 = 高风险 → **不合格**
3. 霉变风险 = 中风险 → **建议人工复核**
4. 根茎完整度 = 低 → **不合格**
5. 色泽均匀度 = 低 → **不合格**
6. 其他情况 → **合格**

> 「建议人工复核」是风险处置状态，不是第三种品质等级。当前版本不允许直接修改模型结果。

## 常见问题

**Q: 提示 API Key 无效或鉴权失败？**
检查 `.env` 中 `ARK_API_KEY` 是否正确、是否开启了对应模型的访问权限。这类确定性错误不会自动重试，修正配置后重启即可。

**Q: 检测结果不稳定怎么办？**
同一图片重复请求的结果应尽可能稳定；若波动较大，确认图片清晰度、背景是否符合建议，并检查 `ARK_MODEL` 配置是否一致。

**Q: 什么情况下会显示「无法评价」？**
图片中不存在可识别黄精主体、多根严重堆叠无法区分主体、目标严重遮挡，或图片严重模糊 / 过暗 / 过曝时，系统无法可靠评价。请重新拍摄更清晰、背景更干净的照片。注意：「无法评价」不代表品质不合格。

**Q: 什么情况下会「建议人工复核」？**
霉变风险被评为「中风险」，即发现局部异常但无法可靠区分普通色差与疑似霉变。这是风险处置提示，建议由人工进一步确认。

**Q: 深褐色的黄精会被判为霉变吗？**
不会。深褐色是九蒸九晒黄精的正常颜色。霉变风险只针对「异常颜色 + 异常纹理 + 异常区域形态」的组合特征，颜色深浅本身不是判定依据。

**Q: JSON 解析失败会崩溃吗？**
不会。程序会先做一次轻量 JSON 提取 / 修复，仍失败则返回用户友好的错误提示，不会暴露内部细节。

**Q: API 超时怎么处理？**
单次请求 30 秒超时，最多自动重试 2 次；重试仍失败会提示用户稍后再试。确定性错误（Key 无效、参数错误、权限错误、模型名称错误）不会重试。

**Q: 如何更换为未来训练的 ResNet18 模型？**
系统定义了统一的 `VisionModel` 接口，当前实现为 `DoubaoSeedModel`。替换模型时只需新增实现类，不需要修改 UI 与业务规则。

**Q: 部署到公网如何开启 HTTPS？**
推荐使用 Caddy + Let's Encrypt 做 `Caddy :443 → Streamlit :8501` 反向代理，安装脚本会在安装时询问域名与证书邮箱并自动配置。

**Q: 顶部状态灯是怎么工作的？为什么显示红色？**
状态灯每 20 分钟真实向模型 API 发送一次极轻量的连通性探测（`max_tokens=1`）。绿点表示探测成功，红点表示 API 无法连通或鉴权失败。若检测能正常出结果但状态灯为红，通常是探测请求被模型接口拒绝（部分视觉模型对纯文本请求有限制），可先忽略或反馈以便调整探测方式。演示模式（`APP_MODE=demo`）下状态灯恒为绿色。

**Q: 粘贴上传或历史持久化不生效？**
`Ctrl+V` 粘贴依赖 `streamlit-paste-button`，历史本地持久化依赖 `streamlit-local-storage`，均已列入 `requirements.txt`。若未安装，应用自动降级：粘贴按钮隐藏、历史退回会话内存储，核心检测流程不受影响。执行 `pip install -r requirements.txt` 可启用完整功能。
